# Change and review guidance

Use for consequential PiCM changes or failed-operation recovery. The [shared contract](../CONTRACT.md) owns scope, privacy, final direction, conversational sign-off, cancellation, and completion; this guide adds review detail, not authorization machinery.

## Proportional review

Choose the most useful diff or file review for linked edits, destructive effects, safety/privacy changes, broad restructuring, or a user request. Show interdependent moves and deletions together so the destination and preserved behavior are inspectable. Small aligned edits need no fixed review categories.

## Validation and recovery

Choose checks that exercise the affected routes and preserved requirements. For an uncertain operation result, inspect relevant eligible state and separate completed, failed, and uncertain effects before proposing an aligned repair. The shared contract governs validation authority, checkpoints, cancellation, and reporting.
